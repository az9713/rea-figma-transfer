Transfer Contract Inspector0.1.0 is an experimental Figma development plugin.

- Capture and compare a declared selection contract covering text, fonts, constraints, layout, bindings and exposed component properties.
- Inspect differences as a readable table; mixed/unavailable values cannot produce a pass.
- Preview and restore one constraints property, rejecting stale state or changed target identity.
- Includes an interactive synthetic browser demonstration and complete source/tests.

Verified: 12 automated contract/API-double checks and 7 Chromium browser checks. Real Figma installation, native undo and compatibility with a specific Figma build remain unverified. Structural mapping requires corresponding root/child ordering and does not prove component or variable identity equivalence. No vendor binary modification or clipboard decoder is included.

Extract the ZIP and import manifest.json as a development plugin in Figma desktop. This is an original MIT-licensed public-API extension, unaffiliated with Figma.
