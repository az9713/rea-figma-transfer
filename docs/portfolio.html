REA project portfolio · 14 experimental releases

What does each tool help you do?

Start with a task you recognize: checking a copied design, correcting subtitles, reviewing a changed model, keeping a quote up to date, or remembering the conditions of a coding run. Each card explains the practical problem and gives an example before sending you to the full guide.

Some projects add a feature inside an existing application; others are separate tools. The description on each card tells you what you actually install. The guides distinguish working examples from integrations that still need testing in the original app.

The order follows the original research priority. Each project has its own source repository, downloadable experimental packages and live explanation.

Research order 1 · Figma

Check what changed when a Figma design was copied.

Transfer Contract Inspector for Figma · A Figma development plugin, with a separate browser demonstration

Two frames can look alike while behaving differently when resized. This plugin compares selected text, font settings and resizing rules before and after a transfer, bringing the checked differences into one report.

For example: The demonstration changes a title's horizontal resizing rule. Capture the original settings, compare the corresponding selection, and inspect that difference. The supported repair can restore one object's saved resizing rule after you preview it.

Research order 2 · CapCut

Correct a subtitle without losing track of the rest of the edit.

Caption Transactions · A separate caption-data editor with a Windows app and browser version

Changing a word in a video subtitle can affect more than its spelling. This editor shows the text and formatting changes together, checks the supported timing and media data, and keeps a record you can undo.

For example: The built-in example replaces 'Qbit' with 'qubit'. That adds a letter. The preview shows how the bold-text boundary moves and lists every caption use affected by the replacement. Unsupported formatting makes the edit stop for review rather than guessing how to move it.

Research order 3 · FreeCAD

Keep a feature attached to the surface you actually meant.

TopoIntent for FreeCAD · A FreeCAD workbench for reviewing links to model surfaces

A sketch or another feature may depend on a particular surface of a CAD model. TopoIntent saves a simple description of that surface, checks it after a model change, and offers a replacement only when one surface clearly matches.

For example: Describe the target as the outside, horizontal surface at the top of the solid. After increasing the box's height, the analyzer explains which faces fail those checks and which one passes. If the top has been split into two equally plausible faces, it asks for a clearer choice instead of repairing the link automatically.

Research order 4 · Cursor

See which file requests Cursor reported around an edit.

Context Evidence Ledger for Cursor · A project event recorder for Cursor, plus a separate viewer

When an AI coding edit surprises you, it helps to inspect the activity around it. This tool records selected events reported by Cursor and puts requests to read files, edits and chat-shortening events on one timeline.

For example: The example names canary-a.txt and canary-b.txt as files you expected to be consulted. It contains a reported read request for the first file but no matching event for the second. That gives you something concrete to investigate; it does not prove the second file was omitted from the model's input.

Research order 6 · Blender

Catch unwanted size changes in your Blender model.

Invariant Ledger for Blender · An experimental Blender add-on for checking model changes

A model can still look fine after an edit even when it has become much larger than you intended. This add-on lets you save a few rules about its size and mesh structure, then check whether your edits broke those rules.

For example: The cube below starts with sides of 2 units: volume 8 and surface area 24. One size control multiplies each side by 2; another multiplies it by 1.25. Together they make each side 5 units, so volume becomes 125 and area becomes 150. The added feature is the report that explains this jump and flags the example's chosen 20% limits. Making the cube bigger is ordinary Blender behavior.

Research order 9 · Obsidian

Find quotes that need checking after a source note changes.

Evidence Anchor for Obsidian · An Obsidian community plugin for Markdown and plain-text notes

Save a passage from a source note and keep a record of the text it came from. If that source changes later, the plugin marks the saved evidence for review instead of silently treating it as unchanged.

For example: Capture a passage, then edit its source. Its status becomes 'Stale', even if your edit was elsewhere in the source. You must review and explicitly revalidate it. If two copies could be the source, the plugin asks you to choose rather than guessing.

Research order 10 · Unity

Check the scene before repeating an editor change.

Guarded Replay Ledger for Unity · An experimental Unity editor package, plus a tested separate Windows checker

Repeating an edit is safer when you first check that it is still aimed at the right object in the right starting state. This tool previews a small set of scene edits and refuses to repeat them when the recorded conditions no longer match.

For example: The browser example changes selected object positions and on/off state. It checks the saved starting scene before allowing the repeated edits. Change that starting state and the example refuses the old edit, showing why a familiar object name is not enough.

Research order 12 · Wispr

Check what your spoken-style maths actually means.

Scientific Dictation · A separate Windows app for checking maths written in spoken-style words

Paste a maths sentence and inspect how it is grouped before copying the result into a document or code. Unclear wording is flagged for clarification instead of being quietly turned into a plausible-looking formula.

For example: Say explicitly whether 'x plus one' is the whole denominator, or whether the final '+ 1' is outside the fraction. Research order 13 · LM Studio

Keep a useful record of each local AI experiment.

LM Experiment Workbench · A separate Windows app designed to connect to LM Studio running on your computer

Save what you asked a local AI server to do, what it reported back, and what it did not tell you. Compare two runs without confusing the settings you requested with the settings the server actually confirmed.

For example: The saved examples change one requested response setting, temperature, which controls sampling randomness. The comparison shows that requested difference separately from the replies. It also leaves missing model or runtime details marked unknown, rather than claiming that the setting alone caused the different answer.
