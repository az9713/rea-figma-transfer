REA Project Portfolio

Fourteen concrete feature experiments, each with its own repository, documentation and bounded evidence. Start with a live guide, inspect the before/after behavior, then choose the relevant package.

These delivery routes differ: ShareX is a modified full application; Figma, FreeCAD, Blender, Obsidian and Unity use extension interfaces; the other projects are independent implementations. They are not fourteen recovered proprietary binaries. Native-host tests and independent fixture tests are identified separately.

Order follows the earlier difficulty/novelty audit. It is not a maturity ranking. A passing hash proves consistency within its stated boundary, not authorship, causal attribution, scientific correctness or complete application equivalence.
