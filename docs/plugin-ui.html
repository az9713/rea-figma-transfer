Transfer Contract Inspector

Two frames can look alike while behaving differently when resized. This plugin compares selected text, font settings and resizing rules before and after a transfer, bringing the checked differences into one report.

Start with the example

The browser example uses invented design records. It lets you understand the comparison without opening Figma; the downloadable plugin is the part intended to run inside Figma.

Your task: Select the corresponding objects in the same order. Read which checked settings differ and which could not be assessed.

Read the plain-language guide, supported uses and testing limits

Repairs affect one constraints property. Other findings require manual review. Missing or mixed values never count as a pass.
